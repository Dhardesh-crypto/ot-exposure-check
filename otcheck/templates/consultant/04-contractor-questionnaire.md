# Contractor access questionnaire

To be sent by the client. Please don't include passwords.

**Contractor:** [name]  **Site or sites:** [sites]

1. Which equipment do you connect to at this site?
2. How do you connect? For example VPN, vendor portal, public address, port forward or cellular router.
3. Did you install any router, modem or SIM here? Please give make, model and location.
4. Which public addresses or ports does your connection use?
5. Do named individuals log in, or is an account shared?
6. Is multifactor authentication required?
7. Do other customers use the same login or configuration?
8. Which of the supplied equipment is no longer supported by its manufacturer?
9. Which firmware version is installed, and when was it last updated?
10. Do you record remote sessions and changes to setpoints, alarms and users?
11. Who should we call in an incident, including out of hours?
12. What monitoring or alarms would stop working if this connection were removed?
